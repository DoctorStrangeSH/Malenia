# Своя Маления

Маления может быть вашей собственной моделью на базе открытой (Gemma 4, Qwen 3.5). Сделать это можно двумя способами.

## 1. Моя Маления — сразу, без обучения

Маления → **Память → Своя модель → «Создать мою Малению»**.
В Ollama создаётся модель `malenia` на основе выбранной локальной модели. В неё встроены ваши факты, предпочтения, уроки и выученные навыки. Модель работает без интернета и сразу становится локальной моделью по умолчанию. Пересоздавайте её время от времени, чтобы добавить новое.

## 2. Дообучение (fine-tuning): Маления учится у вас и у лучших моделей

В набор данных попадают ответы, на которые вы не поставили 👎. Это могут быть ответы Gemini, Groq или локальной модели. Ответы с 👍 учитываются дважды. Обучаясь на них, локальная модель перенимает и ваш стиль, и качество сильных облачных моделей (такой приём называется дистилляцией). Желательно иметь 200 и больше оценённых ответов.

1. Маления → **Память → Своя модель → «Выгрузить данные для обучения»**. Получится файл `malenia-….jsonl`.
2. Обучение на одном из вариантов:
   - **Видеокарта NVIDIA, 8 ГБ** (например, RTX 4060 Ti): модель до 4–9B.
     ```
     pip install unsloth
     python train_malenia.py malenia-….jsonl --base unsloth/Qwen3.5-4B
     ```
   - **Бесплатный Google Colab** (видеокарта T4, 16 ГБ): модели 9–12B, например `--base unsloth/gemma-4-12b-it`. Выберите *Среда выполнения → T4 GPU*, загрузите файлы и выполните те же команды с `!` в начале.
   Точные названия моделей посмотрите на huggingface.co/unsloth: если название изменилось, укажите актуальное в `--base`.
3. Импорт в Ollama:
   ```
   cd malenia-out
   ollama create malenia-pro -f Modelfile
   ```
4. Маления → **Настройки → Модели ИИ → Локальная модель → `malenia-pro`**. Если этот компьютер работает как сервер, модель автоматически станет доступна и на других компьютерах.

Скрипт обучения ещё не запускался на реальном оборудовании. Если Unsloth изменит API, понадобится небольшая правка.
