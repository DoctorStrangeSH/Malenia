# Свой Шерлок

Шерлок может быть вашей собственной моделью на базе открытой (Qwen, Gemma, Llama). Есть два уровня.

## 1. Персональная модель — сразу, без видеокарты

Маления → **Память → Своя модель → «Создать мою модель»**.
Создаётся модель `sherlock-personal` в Ollama на основе выбранной локальной модели. В неё зашиты ваши факты, предпочтения, уроки и выученные навыки. Она работает без интернета и становится локальной моделью по умолчанию. Пересоздавайте её время от времени, чтобы добавить новое.

## 2. Дообучение (fine-tuning): модель перенимает ваш стиль и задачи

Нужно примерно 200 и больше диалогов с оценками 👍/👎. Чем больше оценённых ответов, тем лучше результат.

1. Маления → **Память → Своя модель → «Выгрузить данные для обучения»**. Получится файл `sherlock-….jsonl`: ответы, отмеченные 👍, в нём учитываются дважды, а ответы с 👎 не попадают.
2. Обучение на одном из двух вариантов:
   - **Компьютер с видеокартой NVIDIA, 8 ГБ и больше** (например, ваш сервер):
     ```
     pip install unsloth
     python train_sherlock.py sherlock-….jsonl --base unsloth/Qwen3-8B
     ```
   - **Бесплатный Google Colab** (видеокарта T4): создайте блокнот, выберите *Среда выполнения → T4 GPU*, загрузите в него `train_sherlock.py` и jsonl, затем выполните те же две команды с `!` в начале. Модель 4–8B на 200–1000 примерах обучается за 20–60 минут.
3. Импорт в Ollama на компьютере, где работает модель:
   ```
   cd sherlock-out
   ollama create sherlock -f Modelfile
   ```
4. Маления → **Настройки → Модели ИИ → Локальная модель → `sherlock`**. Если этот компьютер работает как сервер, модель автоматически станет доступна и на рабочем ноутбуке.

Скрипт обучения ещё не запускался на реальном оборудовании. Если Unsloth изменит API, понадобится небольшая правка.
